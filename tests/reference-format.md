# Ручной эталон качества

Эталон заполняет человек. Он используется только при сравнении и не передаётся OCR. Реальные эталоны храните локально.

```json
{
  "Name": "Искусственный контрольный комплект",
  "KnownFindings": [
    { "Code": "123-45-6789-ИЛО4.1.2", "Topic": "Название книги в ИУЛ" }
  ],
  "NegativeChecks": [
    { "Code": "123-45-6789-ИЛО4.1.1", "Photo": 2,
      "Topics": ["Подписи в ИУЛ: визуальная проверка", "Подписи: проверка отдельных строк"] }
  ],
  "Fields": [
    { "Photo": 2, "Field": "CRC", "Value": "1234ABCD" },
    { "Photo": 2, "Field": "Page", "Value": "1" },
    { "Photo": 2, "Field": "Pages", "Value": "3" },
    { "Photo": 2, "Field": "Revision", "Value": "2" }
  ]
}
```

`KnownFindings` — настоящие проблемы. `NegativeChecks` — проверки без проблемы по ручному просмотру. `Topic` совпадает с темой в отчёте; `Topics` позволяет перечислить равнозначные темы разных версий. Необязательный `Photo` ограничивает проверку страницей. Сравнивайте запуски с одинаковым порядком страниц.

`Fields` задаёт эталонные значения строками; пустая строка означает отсутствие поля. Оценка отделяет неверное чтение от нераспознанного. Не размеченные находки учитываются отдельно и не объявляются верными или ложными.
